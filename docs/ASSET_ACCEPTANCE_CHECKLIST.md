# Asset Acceptance Checklist

Use this checklist for every terrain sheet, environment asset pack, character sheet, and assembled map.

## Visual match
- [ ] Matches the approved reference's diagonal 3/4 perspective.
- [ ] Uses compatible pixel density, scale, palette, outline treatment, and lighting.
- [ ] Has clean, intentional pixel clusters and readable silhouettes.
- [ ] Material textures are distinct and visually coherent.

## Technical quality
- [ ] Correct dimensions and documented tile/frame size.
- [ ] Transparent backgrounds are clean where required.
- [ ] No stray pixels, halos, accidental blur, or compression artifacts.
- [ ] Pivot/origin and intended render layer are documented.
- [ ] Source files are retained and independently editable.

## Modularity
- [ ] Objects are separate assets, not flattened into a scene.
- [ ] Terrain includes required edges, corners, inner corners, and transitions.
- [ ] Variants are genuinely distinct and avoid obvious repetition.
- [ ] Tiles connect without seams in a test map.

## Final validation
- [ ] Tested at normal gameplay zoom.
- [ ] Tested in the selected map editor.
- [ ] Exported and checked in the target runtime.
- [ ] Third-party source and license recorded, if applicable.

An unchecked critical item means the asset is not approved for production.
