# Forest demo map

A 20×14 composition smoke test built from the procedural ground materials, 47 connected blob masks, and independently extracted CC0 tree/plant PNG sprites. It includes a winding river with sand bank, a dirt footpath, stone patches, mixed grass and layered props.

Files: forest_demo_map.png (combined preview), forest_demo_ground.png (terrain only), forest_demo_props.png (transparent prop layer), forest_demo_map_2x.png (nearest-neighbour 2× preview), and forest_demo_map.json (cell layers and prop placements).

This is an integration test map, not final hand-authored world art.
