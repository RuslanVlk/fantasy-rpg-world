# Forest tree sprites

Twelve separate transparent PNG tree sprites extracted from the Kenney Roguelike/RPG CC0 atlas: six 16x16 small trees and six 16x32 two-cell tall trees.

Source and license are recorded in trees.json. Original source atlas is preserved under assets/third_party/kenney_roguelike/.

trees_contact_sheet.png is a review preview only. Import the individual PNG sprites for map placement.
