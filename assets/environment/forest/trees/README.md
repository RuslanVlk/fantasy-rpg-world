# Forest tree sprites

Fifteen separate transparent PNGs from the Kenney Roguelike/RPG CC0 atlas: six small 16x16 trees, six tall 16x32 trees, two fruit trees and one 16x48 dead tree.

Source cells and license are recorded in trees.json. The original atlas is preserved under assets/third_party/kenney_roguelike/.

trees_contact_sheet.png is a review preview only. Import the individual PNG sprites for map placement.
